<objective>
Establish the audit trail for the AI-01/AI-02 scope amendment by patching three planning files with GFM strikethrough markers and dated amendment notes. This is a docs-only commit — no code, no config. The patches make the original spec wording visible-but-superseded so future readers can see both the original intent and the Phase 2 refinement reason.

Purpose: D-06 / D-09 (CONTEXT.md). The Phase 2 discussion concluded that "provider-agnostic Anthropic + OpenRouter" was best refined to "OpenRouter-only with model-level provider routing" because (a) cost flexibility is fully delivered, (b) Anthropic models stay reachable via `anthropic/*` model prefix, (c) one client = no abstraction layer to maintain, (d) free models become a $0/month option. The original wording is not wrong — it's superseded. The strikethrough convention preserves the historical context.

D-09 establishes this convention for the first time in this project; the GFM idiom locked is `~~original text~~ → **Amended YYYY-MM-DD in Phase N discuss:** new text.` PROJECT.md uses a lighter variant (Outcome cell append) per D-08's "single-line outcome note".

Output: One git commit `docs(spec): amend AI-01/AI-02 to OpenRouter-only` covering 3 planning-doc files. Runs in Wave 2 (parallel with PLAN-03), depends on PLAN-01's code commit being HEAD so the amended wording accurately reflects shipped behaviour.
